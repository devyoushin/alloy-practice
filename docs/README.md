# Alloy Docs

Alloy 문서는 학습 문서, 규칙, 템플릿, 에이전트 프롬프트를 함께 관리합니다.

| 폴더/문서 | 내용 |
|------|------|
| `install.md` | Helm, systemd, Docker Compose 설치 |
| `architecture-guide.md` | Alloy 배포 구조와 데이터 흐름 |
| `config-language-guide.md` | River 설정 언어 |
| `kubernetes-discovery-guide.md` | Kubernetes service discovery |
| `metrics-guide.md` | Prometheus scrape와 Mimir remote_write |
| `logs-guide.md` | Kubernetes 로그 수집과 Loki 전송 |
| `traces-guide.md` | OTLP traces 수집과 Tempo 전송 |
| `otel-guide.md` | OpenTelemetry 컴포넌트 통합 |
| `clustering-guide.md`, `monitoring-guide.md` | 클러스터링과 자체 모니터링 |
| `rules/` | 문서 작성 및 운영 규칙 |
| `templates/` | 서비스 문서, 런북, 장애 보고서 템플릿 |
| `agents/` | Claude 에이전트 프롬프트 |

처음 읽을 문서는 `install.md`입니다.
